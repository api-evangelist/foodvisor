# Foodvisor

> Foodvisor is a French mobile nutrition platform whose app identifies food from a photograph
> using computer vision and returns calories, macronutrients and portion estimates. Foodvisor
> formerly sold that capability to developers as the Foodvisor Vision API; that public developer
> product has been retired and Foodvisor currently publishes no API.

This file is GENERATED by API Evangelist from the public record in this repository. It is not
published by Foodvisor. Everything below was probed or searched on 2026-09-10.
Source of record: https://raw.githubusercontent.com/api-evangelist/foodvisor/refs/heads/main/apis.yml

## Status for agents

- There is no callable Foodvisor API an agent can reach. No OpenAPI, AsyncAPI, GraphQL SDL,
  Protobuf, WSDL or Postman collection is published anywhere.
- The Vision API product page https://www.foodvisor.io/en/vision/ returns HTTP 404.
- The Vision API documentation host vision.foodvisor.io does not resolve (NXDOMAIN).
- No MCP server, no A2A agent card, no llms.txt and no /.well-known document is served on any
  Foodvisor host.
- Do not attempt to call api.foodvisor.io. It is the private backend for the consumer mobile
  app, it is not a published API, and it carries no public contract or terms of use.
